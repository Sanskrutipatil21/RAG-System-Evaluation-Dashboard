# 🤖 RAG System Evaluation Dashboard

### Enterprise AI Analytics Dashboard | Power BI | DAX | Power Query | Excel | Figma

An end-to-end Business Intelligence solution developed to analyze and evaluate Retrieval-Augmented Generation (RAG) systems by transforming AI evaluation data into interactive dashboards that provide actionable insights into retrieval effectiveness, hallucination detection, model reliability, corpus health, operational performance, and enterprise AI decision-making.
